# 性能记录与验证范围

本页是移除本机路径、进程标识和网络信息后的公开摘要，不是跨设备性能保证。

## 测量条件

- 日期：2026-11-01。
- Apple M1，8 核，16 GB；macOS 27.2。
- 每种状态测量 30 秒，均为标准策略、双向菜单栏网速、面板关闭。
- CPU 是进程 CPU 时间差 / 墙钟时间，以一个逻辑核心的 100% 为基准；不包含 WindowServer。
- 物理内存来自 `vmmap` 的 Physical footprint；RSS 包含共享驻留页，是另一口径。
- 0.4.1 和 0.5.0 冷启动记录来自同一机器和构建环境。使用设置后的状态单独列出。

| 版本与状态 | 平均 CPU | Physical footprint | RSS |
| --- | ---: | ---: | ---: |
| 0.4.1 冷启动后台 | 0.833% | 13.4M | 67.31 MiB |
| 0.5.0 冷启动后台 | 0.900% | 14.2M | 73.73 MiB |
| 0.5.0 使用并关闭设置后的后台 | 0.800% | 38.6M | 127.06 MiB |

冷启动对照未见明显数量级回归；该单次短测不能证明性能提升。使用界面后的内存占用不能直接用于判断缓存或泄漏，仍需长期驻留和重复开关验证。

## 在自己的机器上测量

先关闭面板和设置，固定网速显示与采样模式，再对指定进程运行仓库中的测量脚本：

```sh
python3 scripts/measure.py <PID> 30 /tmp/macstatus-measurement.json
```

脚本读取给定进程的 CPU 时间、RSS 和 `vmmap` 汇总，不向应用施加负载，不向外部服务上传结果。原始报告可能包含本机进程标识，分享前请检查。
