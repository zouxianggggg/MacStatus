# 指标与采样说明

MacStatus 使用 Mach、IOKit、BSD / Foundation 和系统框架读取本机信息，没有第三方运行时包依赖。下面的口径有助于解释与其他监控工具之间的差异。

## CPU 与进程

- 整机使用率按机器总容量归一化为 0–100%；进程使用率按单核心 100% 计算，可超过 100%。
- 进程 CPU 从 Mach tick 差分按本机时间基准换算，首次采样等待基线；PID 重用或计数回退会重建基线。
- 各核心和 1 / 5 / 15 分钟负载仅在处理器卡片展开时读取。负载是任务数，不是百分比。
- CPU / 内存排行仅在对应卡片展开时读取，至少间隔 5 秒，仅包含当前权限可读取的进程。进程 RSS 包含共享页面，不能相加作为整机已用内存。

## 内存

- 来自 Mach 页计数。应用内存估算为 active + inactive − file-backed − purgeable；已用为应用 + wired + compressor，并限制不超过物理内存。
- 缓存估算、采样时刻与内存压力口径可能与活动监视器不同。
- 页读入 / 写出是开机以来累计，不等于 swap 用量；交换空间单独读取。

## 网络

- 合计活动的 `en` 接口，避免把物理、桥接与 VPN 隧道的同一流量重复累加。当前不是逐应用流量监控，也不是全部虚拟网卡的合计。
- 使用系统 64 位接口计数。累计量不是应用启动后累计；接口重连、归零或更换会重建速率基线。
- 公网 IPv4 / IPv6 是本应用 HTTPS 请求观察到的出口，可能经过系统代理、VPN 或分流；不代表所有应用的全部流量。IPv6 查询失败不等同于系统没有 IPv6。
- 国旗表示 IP 数据库归属地。数据库查询失败时保留已确认地址，不猜测国家。
- DNS 为系统全局配置，不覆盖所有按域名分流的解析器；活动 `utun` 接口也可能来自系统服务，不能单凭它判断 VPN 已接管全部流量。
- Wi-Fi 信号、噪声、信道和协商速率仅展开网络时每 30 秒读取，不扫描附近网络或请求定位。协商速率不是实际吞吐率。

## 存储、电池与系统

- 存储容量展示数据卷；普通可用容量与重要用途可用容量分开显示，后者可能包含可清除空间。APFS 多卷共享容器容量，不能将各卷容量直接相加。
- 磁盘读写为可读取块存储驱动的合计，不是仅该 APFS 卷的活动；首次读取不制造速率。
- 电池满充 / 设计容量比来自原始容量字段，不等同于系统设置中的健康百分比。电池端功率不是整机功耗，适配器功率是额定值。
- 系统热状态是 macOS 给出的等级，不是摄氏温度。不可用字段不会填入模拟数值。

## 刷新与历史

标准模式查看时 2 秒更新，节能模式 5 秒；后台完整指标约每 10 秒 / 30 秒读取。启用菜单栏网速只提高网络计数频率。所有采样共用一个定时器，不为设置、复制或引导增加轮询。

趋势记录只在内存中保留最多 15 分钟 / 450 个点；图表展示最近两分钟。启动从右侧积累真实样本，单点不连线，缺失值和长间隔断开。没有逐帧图表动画，卡片使用短过渡并尊重系统减少动态效果。
