# 隐私说明

适用于当前 0.5.0 源码预览。未来行为变化应与代码和本文同步说明。

## 本地监控

系统指标在本机读取。应用没有账号、遥测、广告 SDK 或自动上传问题报告；趋势只留在内存，最多 15 分钟 / 450 点。偏好通过系统 UserDefaults 保存在本机。

系统登录项只在用户明确切换开机启动时向 macOS 注册或注销，不默认启用。登录项是否允许启动由系统状态决定。

## 可关闭的在线查询

打开网络详情并允许在线查询时：

1. 通过 HTTPS 请求 `api.ipify.org` 和 `api6.ipify.org` 获取各地址族的请求出口。
2. 将成功确认的公网 IP 通过 HTTPS 发给 `ipwho.is` 查询国别、网络提供商和 AS。

这些服务自然会看到请求来源的公网 IP。MacStatus 不额外附带本机指标、局域网地址或设备标识。详情关闭会取消未完成请求；隐藏时不发起查询。结果只在内存缓存五分钟，网络身份变化会使缓存失效。手动刷新可以重新查询。

在「设置 → 隐私」关闭查询，会取消请求并清除结果；本地网速、接口与其他系统指标仍可使用。第三方服务的可用性及数据库准确性不由本项目保证。

## 反馈与截图

应用内问题报告仅包含版本、系统版本、机型、芯片、内存及采样设置；复制后由用户决定是否分享。不会自动发送。

公开 Issue、你附加的截图或自行运行的 `--diagnose` 输出可能包含 IP、DNS、进程名称或其他环境细节。`--diagnose` 的完整快照不同于应用内脱敏反馈报告，请先检查并删去不希望公开的信息。

GitHub Issues、README 徽章和 GitHub 本身属于仓库网页，不是应用中的遥测或后台服务；访问这些页面适用相应服务的规则。
